# 안당문화체육재단 재단 소개 포털 — 사용법

재단법인 안당문화체육재단을 소개하는 웹 페이지입니다. HTML 파일 하나(`index.html`)로 되어 있어 별도 설치 없이 바로 열 수 있습니다. 바이브코딩 실습용 자료입니다.

## 폴더 구성

```
3.부서포털_바탕화면/
├── index.html                 ← 포털 페이지 (이 파일만 열면 됩니다)
├── README.md                  ← 이 사용법
├── files/                     ← 자료실에서 내려받는 파일
│   ├── andang-brochure-2026.pdf     재단 브로슈어 2026 (8쪽)
│   └── andang-articles-2026-06.pdf  재단 정관 2026.06.08 개정 (7쪽, 개인정보 제외본)
└── 이전버전/
    └── andang-foundation_v1.html    바꾸기 전 원본 사본
```

## 여는 방법

1. 파일 탐색기에서 `index.html`을 더블클릭합니다. 기본 브라우저(Chrome, Edge 등)로 열립니다.
2. 자료실 다운로드가 되려면 `index.html`과 `files/` 폴더가 **같은 위치**에 있어야 합니다. 다른 곳으로 옮길 때는 폴더째 옮기세요.
3. 글꼴(Noto Sans KR)은 인터넷에서 불러옵니다. 인터넷이 안 되면 맑은 고딕으로 보입니다.

## 화면 구성

| 메뉴 | 내용 |
|---|---|
| 홈 | '재단 소개 포털' 타이틀과 대표 문구, 바로가기 버튼 |
| 재단 소개 | 인사말, 재단 기본 정보(재단명·영문명·주소·전화), 핵심 가치 3가지 |
| 재단 사업 | 사업 카드 2개(비인기 종목 선수 육성 / 사회인 생활체육). '자세히 보기'는 재단 공식 홈페이지로 연결 |
| FAQ | 자주 묻는 질문 10개. 검색창·카테고리 버튼으로 걸러 보기, 질문을 누르면 답이 펼쳐짐 |
| 자료실 | 번호·자료명·형식·등록일 목록. 자료명을 누르면 내려받음 |

- 위쪽 메뉴는 스크롤해도 화면 위에 고정되고, 누르면 해당 영역으로 부드럽게 이동합니다.
- 지금 보고 있는 영역의 메뉴가 남색으로 표시됩니다. 맨 아래까지 내리면 '자료실'이 표시됩니다.
- **모바일(폭 860px 이하):** 메뉴가 오른쪽 위 ☰ 버튼으로 접힙니다. 누르면 펼쳐지고(버튼이 ✕로 바뀜), 메뉴 항목을 누르거나 메뉴 바깥을 누르거나 Esc 키를 누르면 자동으로 닫힙니다.
- **다크모드:** 오른쪽 위 ☾ 버튼을 누르면 어두운 화면으로, ☀ 버튼을 누르면 밝은 화면으로 바뀝니다. 고른 모드는 브라우저에 기억되어 다음에 열 때도 유지됩니다. 직접 고른 적이 없으면 컴퓨터·휴대폰의 다크모드 설정을 따릅니다.
- 오른쪽 아래 ↑ 버튼을 누르면 맨 위로 돌아갑니다.

### FAQ 찾기

- **검색창:** 단어를 입력하면 질문과 답변에 그 단어가 들어간 FAQ만 남고, 찾은 단어가 금색으로 표시됩니다. 단어가 답변에만 있으면 답변이 자동으로 펼쳐집니다.
- **여러 단어:** 띄어 쓴 단어는 모두 들어 있는 FAQ만 찾습니다. 예: `정관 개인정보`
- **카테고리 버튼:** 전체 / 재단 소개 / 사업·지원 / 기부·공시 / 문의. 검색어와 함께 쓰면 두 조건을 모두 만족하는 FAQ만 보입니다.
- 결과가 없으면 안내 문구와 '전체 질문 보기' 버튼이 나옵니다. 검색창 오른쪽 × 버튼으로 검색어를 지울 수 있습니다.

## 내용 고치는 방법

`index.html`을 메모장이나 VS Code로 열어 고칩니다. 바이브코딩 실습에서는 Claude에게 아래 예시처럼 요청해도 됩니다.

### 자료실에 파일 추가

1. 파일을 `files/` 폴더에 넣습니다. 파일 이름은 영문·숫자·하이픈(-)으로 짓는 것이 안전합니다. 예: `andang-report-2026.pdf`
2. `index.html`에서 `id="fileList"`를 찾아, 그 안에 아래 한 줄 묶음을 **맨 위에** 추가합니다(최신 자료가 위로 오게).

```html
<li>
  <span class="col-no">3</span>
  <a class="col-title" href="files/andang-report-2026.pdf" download="내려받을_때_이름.pdf">자료 제목</a>
  <span class="col-type">PDF</span>
  <span class="col-date">2026-11-19</span>
</li>
```

- 번호는 기존 최대 번호 + 1로 씁니다.
- 자료가 하나도 없으면 "등록된 자료가 없습니다."가 자동으로 보입니다.

> 요청 예시: "files 폴더에 넣은 ○○.pdf를 자료실 맨 위에 추가해줘"

### FAQ 추가·수정

`class="faq"` 안에 질문 하나가 아래 묶음 하나입니다. 복사해서 질문과 답만 바꾸면 됩니다.

```html
<div class="faq-item reveal" data-category="business">
  <button class="faq-q">질문</button>
  <div class="faq-a"><p>답변</p></div>
</div>
```

`data-category`에는 카테고리 이름을 넣습니다: `about`(재단 소개), `business`(사업·지원), `donation`(기부·공시), `contact`(문의). 새 카테고리가 필요하면 `class="faq-cats"` 안에 버튼을 하나 추가하고 `data-cat`에 같은 이름을 씁니다.

> 요청 예시: "FAQ에 '자원봉사도 할 수 있나요?' 질문을 추가해줘"

### 사업 카드 수정

`id="business"` 영역의 `<article class="card">`가 카드 하나입니다. 윗부분 색은 `card-top navy`(남색) 또는 `card-top gold`(금색)으로 정합니다.

### 재단 정보 수정

주소·전화번호는 '재단 소개'의 정보 박스(`class="info-box"`), FAQ 10번, 맨 아래 푸터 **세 곳**에 있습니다. 바꿀 때는 세 곳을 모두 고치세요.

## 디자인 규칙

색은 재단 CI에서 가져왔습니다. 새 요소를 만들 때도 아래 값을 쓰면 페이지와 어울립니다. 값은 `index.html` 맨 위 `:root` 안에 모여 있습니다.

| 이름 | 색 | 쓰는 곳 |
|---|---|---|
| `--navy` | #212D69 | 메인 색. 제목, 상단 배경, 활성 메뉴 |
| `--gold` | #8B734B | 포인트 색. 주 버튼, 섹션 라벨 |
| `--silver` | #9FA2A6 | 장식용. 글자에는 쓰지 않음 |
| `--text` | #3A3D4A | 본문 글자 |
| `--bg` | #FAFAFC | 페이지 바탕 |

- **다크모드 색:** 글자·바탕·테두리는 `--surface`(카드 바탕), `--heading`(제목), `--accent-text`(금색 글자), `--brand-fill`(활성 버튼) 같은 역할별 변수로 칠합니다. 라이트 값은 `:root`에, 다크 값은 `:root[data-theme="dark"]`에 있습니다. 새 요소를 만들 때 `#FFFFFF` 같은 색을 직접 쓰지 말고 이 변수를 쓰면 다크모드에서도 자동으로 맞춰집니다.
- 다크모드에서 로고는 CI 색을 지키기 위해 흰 바탕 위에 표시됩니다.
- 글꼴: Noto Sans KR (제목 900, 질문·버튼 700, 본문 400)
- 섹션 위아래 여백 100px, 본문 최대 폭 1120px
- 로고는 CI 국문 시그니처 이미지가 HTML 안에 들어 있습니다. 모양과 색은 바꾸지 않습니다.
